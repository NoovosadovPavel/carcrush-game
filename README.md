# 🚗 CarCrush

**Три в ряд со значками автомобилей!**

Классическая механика match-3, но вместо цветных шариков — машинки и логотипы автомобильных брендов.

## 🎮 Играть

**GitHub Pages:** https://noovosadovpavel.github.io/carcrush-game/

Или локально:
```bash
python3 -m http.server 8080
# открой http://localhost:8080
```

## ✨ Особенности

- **Два режима игры:**
  - 🚘 **Нарисованные машинки** — седан, внедорожник, такси, полиция, скорая, пожарная, автобус
  - 🏷️ **Марки автомобилей** — Mercedes, BMW, Audi, VW, Opel, Nissan, Toyota
- Все элементы — рукописные **SVG-файлы**
- Полная механика match-3: свап, совпадения, гравитация, каскадные комбо
- Анимации: обмен, падение существующих, появление новых сверху с отскоком
- Счёт, множитель комбо, подсказки, перемешивание при тупике
- Canvas-рендеринг с эффектами свечения и теней
- Адаптивная вёрстка для мобильных

## 🛠️ Технологии

- HTML5 Canvas
- CSS3 (анимации, glassmorphism)
- Vanilla JavaScript
- SVG-графика

## 📂 Структура
