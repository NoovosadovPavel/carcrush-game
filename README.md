# 🚗 CarCrush

**Три в ряд со значками автомобилей!**

Классическая механика match-3, но вместо цветных шариков — машинки и логотипы автомобильных брендов.

## 🎮 Играть

**GitHub Pages:** https://noovosadovpavel.github.io/carcrush-game/

Или локально:
```bash
python3 -m http.server 8080
# открой http://localhost:8080
```

## ✨ Особенности

- **Один режим игры с логотипами брендов:**
  - 🏷️ Mercedes, BMW, Ferrari, Ford, Nissan, Porsche, VW
- Все элементы — **SVG-файлы** (кастомные логотипы брендов)
- 📋 **5 уровней с разными заданиями:**
  - Уровень 1 — собрать **12 Ferrari** за 20 ходов
  - Уровень 2 — набрать **500 очков** за 20 ходов
  - Уровень 3 — получить **2 Monster Grafio** за 25 ходов
  - Уровень 4 — достичь **комбо x3** за 25 ходов
  - Уровень 5 — набрать **1000 очков** за 30 ходов
  - После прохождения — поощрительная надпись
- Полная механика match-3: свап, совпадения, гравитация, каскадные комбо
- 🎁 **Бонусные фишки:**
  - **Monster Grafio** — появляется при совпадении 4 в ряд/столбец. При клике очищает весь ряд или весь столбец
  - **Red Bull** — появляется при совпадении 5+ фишек. При клике взрывает квадрат 3×3
- 🔊 **Звуки:** свап, совпадения, комбо, бонус, победа, поражение
- 👆 **Drag & Drop:** поддержка мыши и тачскрина (перетаскивание фишек)
- 📱 **Мобильная оптимизация:** ускоренные анимации, throttled pulse, passive:false для touch
- Анимации: обмен, падение существующих, появление новых сверху с отскоком, эффект взрыва
- Счёт, множитель комбо, подсказки, перемешивание при тупике
- Прогресс-бар выполнения задания уровня
- Пульсирующее свечение бонусных фишек
- Canvas-рендеринг с эффектами свечения и теней
- Адаптивная вёрстка для мобильных

## 🛠️ Технологии

- HTML5 Canvas
- CSS3 (анимации, glassmorphism)
- Vanilla JavaScript
- SVG-графика
